# Физика в быту

Школьный проект по физике (7–9 класс): текст выступления на четырёх участников и презентация.

- `out/Физика_в_быту_текст.docx` — текст, поделённый по участникам (введение, гипотеза, 4 главы, заключение, литература, памятка).
- `out/Физика_в_быту_презентация.pptx` — 19 слайдов; текст каждого участника продублирован в заметках к слайдам.

Текст хранится в `scripts/content.py` и попадает и в документ, и в заметки. Пересборка:

```bash
uv venv .venv && uv pip install --python .venv/bin/python python-docx python-pptx matplotlib pillow numpy
./scripts/build.sh   # при наличии LibreOffice дополнительно рендерит PNG в build/render для проверки
```

Иконки рисуются шрифтом Noto Color Emoji (`fonts-noto-color-emoji`).
